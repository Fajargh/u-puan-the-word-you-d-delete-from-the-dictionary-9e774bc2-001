A tiny program that writes the one word to delete from the dictionary forever: **onomatopoeia** — the word for words that sound like what they mean, famously hard to spell and pronounce, and itself the prime example of what it describes. Erasing it removes the word that names its own trick.

## Run it

```sh
python3 main.py
```
